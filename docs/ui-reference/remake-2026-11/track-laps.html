Track laps, remade

Today a run you drove lives on six pages: Track day, Analyze › Laps, Progress, Records, Library › Race results and the Garage. Each has its own filters and its own drop-down to pick the run. This remake gives every run one home, organised by car, track and lane, the only grouping where lap times can be compared.

  • Replaces: Analyze › Laps, Compare (runs), Progress and Records, and Library › Race results. Track day stays as the place to log a run (its own remake comes later).
  • Kept: every number the pages show today (best eligible lap, median, middle 50% spread, best 5 in a row, stints, excluded laps, what was raced), Paddock imports and manual runs, Analyze/Compare/Export.
  • New, each one for you to approve: a note on every run, a tag (club night, test, race), the record marked where it was set, and "what changed" shown on the run itself.

A · Run Log

Calm and list-first, like a logbook.

  • Left: your lines (car · track · lane), with their record.
  • Top: the pace trend of that line, with the record and how much you gained.
  • Below: every run as one row; a run opens in place as a run sheet. Tick two runs to compare them.

B · Pace Wall

Visual-first, like a timing screen: you see every lap at once.

  • Top: pick the car, then the track and lane.
  • A scoreboard: record, pace now, gained, consistency.
  • The wall: one row per run, one square per lap, coloured by how close it was to the record. A run opens in the side panel.
  • Underneath, a change ledger: which setup change moved the pace, and by how much.
