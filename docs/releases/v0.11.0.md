**SlotForge Telemetry 0.11.0 makes setup work easier with guided Driver Feedback, a compact workbench and drag-and-drop ballast planning.**

### Driver Feedback

A new main-menu page replaces Predicted Performance. Start with what your car does—tipping, sliding, hopping, losing the guide, difficult braking or inconsistent laps—and follow five clear steps:

1. **Your experience:** describe the behaviour. No measurements needed.
2. **First checks:** choose a practical check before changing parts.
3. **Your setup:** include your workbench or open a saved setup; existing values are reused.
4. **Look deeper:** add optional measurements for more specific calculations and comparisons.
5. **Try & learn:** record one tested change and its outcome, then save or export the investigation.

All measurements remain optional. Advice distinguishes observations, measurements and proposals. Recorded outcomes retain their setup context; later changes are identified rather than silently treated as the same test. Owner reports provide ideas to investigate, not universal brand rankings or promised lap-time gains.

### A shorter, clearer workbench

- Collapse input folders and see useful summaries without opening each one.
- Related live results open alongside the selected input area.
- Pin result groups to keep them visible, or close all unpinned groups.
- Your folder preferences are remembered separately from car data.

### Visual ballast planning

Click the chassis to place ballast, enter its weight, then drag it into position. Existing points can be dragged too; choose **Update part** to apply an edit. Keyboard arrows and exact coordinate fields remain available.

You can record placements without measuring the car first. These stay relative to the drawing. Add actual dimensions and confirmed support readings when you want calculated balance and support loads. The drawing never invents measurements, and a planned change never alters the measured baseline.

### Review and fixes

Driver Feedback now reuses total mass calculated from front and rear scale readings, with its source shown. Ballast edits retain their coordinate meaning when dimensions are removed. Updated documentation and expanded regression checks cover saved data, guidance, dragging, folders, Paddock/manual laps and both themes.

### Updating

Export backups of your setup library and lap data, close Telemetry, and replace the old application with the new download. Existing local data is retained; older setups receive safe defaults for the new optional fields. New drawing-relative ballast plans should be used with this version or later.

See the [installation instructions](https://github.com/theDutchmanJames/SlotForgeTelemetry#how-to-install) for platform-specific help. Windows and macOS builds are not publisher-signed/notarized; the README explains the operating-system prompts.
