**SlotForge Telemetry 0.13.0 gives Driver Feedback distinct routes for what your car actually does, with clearer follow-up questions and an easy way to start over.**

### Follow the behaviour

Tipping, sliding, sudden catching, guide escape, hopping, lack of power, braking, deterioration and inconsistent laps each lead to their own questions. If you are unsure, start with the movement you can observe.

“My car lacks power” now distinguishes weak acceleration, low straight-line speed, revving without movement, cutouts, fading performance, tight-turn resistance and poor trigger response. Tyre-to-rim slip, wheelspin and loose drivetrain parts receive different checks. Controller and power advice distinguishes analogue from digital systems and asks whether other cars affect the behaviour.

### Start simple, measure when useful

- Answer one useful question at a time, skip it, or revisit earlier answers.
- See the effort, equipment and purpose of a check, with an easier alternative where practical.
- Reuse your existing measurements for relevant calculations without entering them again.
- Follow setup-guide additions for recently trued tyre shoulders, body versus pod adjustments, pickup and controller checks.

Every input remains optional. Suggestions explain the evidence and trade-offs; they do not claim a guaranteed diagnosis or lap-time gain.

### Keep track of what worked

Inspections distinguish a fault, no fault, an uncertain result and an unavailable check. Setup changes distinguish improvement, no clear difference and a worse result. An inconclusive test does not rule out a possible cause.

Individual checks only need repeating when relevant setup details change. Old answers from an inactive branch no longer steer a different route. If a new problem appears, save the first investigation as a separate library entry and continue with the same car measurements.

### Start over

The **Start over** button at the top of Driver Feedback clears its answers, notes, recorded checks and test outcome after confirmation. Your car setup, measurements and saved library entries are kept. Cancel leaves the investigation untouched.

### Review and compatibility

Reviewed route logic, calculation connections, saved histories, reset behaviour, cancellation, exports and light/dark layouts. Local validation passed 191 automated tests, all 12 desktop suites and Windows packaging; five environment-dependent tests were skipped locally. The release workflow also checks and builds on Windows, Linux and macOS before preparing the downloads.

Existing setups remain readable. Export backups before updating, and use this version or later to retain the new route answers and inspection records.

### Updating

Export backups of your setup library and lap data, close Telemetry, and replace the old application with the new download. Existing local data is retained.

See the [installation instructions](https://github.com/theDutchmanJames/SlotForgeTelemetry#how-to-install) for platform-specific help. Windows and macOS builds are not publisher-signed/notarized; the README explains the operating-system prompts.
