**SlotForge Telemetry 0.7.0 connects your setup calculations with measured race results.**

### New in this release

- Connect to Paddock using its existing Dealership password, with local-network discovery or a manually entered address.
- Import reviewed Timing sessions delivered to Paddock, including individual laps, lanes, drivers and captured car configurations.
- Analyze lap progression, median pace, consistency and best consecutive five-lap runs. Inspect excluded laps without counting them in pace statistics.
- Compare two runs in a simple table. Performance colours require compatible track/lane/source and your confirmation of driver and conditions.
- Browse an offline race library and derived best laps, with JSON export. Corrections, withdrawals and restored history reconcile safely; automatic refresh is available on supported hosts.
- Retains the setup calculator, saved setup library, themes and calculation reference. The corrected Telemetry licence wording is now embedded in these packages.

**Paddock requirement:** use a Paddock build that supports Telemetry result downloads. Older installed builds may need updating. These are reviewed historical sessions, not live sensor telemetry or Timing's complete official record database.

### Updating

Export your setup library as a backup, close the old app, then open the new version. Your existing application profile, setups and themes are retained. Race imports are stored separately; Paddock remains their source of truth. Passwords stay in memory until disconnect or exit.

### Validation and known limits

The pre-release review passed 57 automated tests, Windows desktop workflows and interoperability tests against Paddock's actual host implementation using artificial data over localhost. It repaired snapshot consistency, receipt-only correction handling, driver comparison assumptions, chart gaps and failed reconnection state. A real two-computer network test remains outstanding; discovery and firewall behaviour can vary.

Windows is unsigned. macOS is ad-hoc signed, not Developer ID signed or notarized; see the installation guide for first-launch prompts. Native Linux/macOS packages are built in GitHub Actions; interactive desktop testing was performed on Windows.
