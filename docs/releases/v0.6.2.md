**The first public release of SlotForge Telemetry: a standalone workbench for understanding and comparing slotcar setups.**

Enter gearing, motor, tyres and weight; explore the results; save experiments in a local library. Works offline with no account or timing hardware required.

### Included

- **Telemetry:** live gearing, rollout, theoretical speed, motor power and power-to-weight, with visible input shortcuts.
- **Analyze:** motor curves, ideal acceleration, ballast placement/centre of gravity, tyre wear, gear clearance, gear finder and measured lap speed.
- **Compare:** two saved setups side by side with changes and contextual highlights.
- **Library:** names, notes, search, duplicate, rename, delete/undo and backup import/export.
- **Settings:** eight themes, custom colours and a complete calculation reference.
- The stopwatch desktop icon and Paddock's category-coloured vector artwork.

### Updating an earlier local build

Use **Library → Export library** to make a backup, then close the old app before opening this version. The existing **SlotForge Calculator** profile is retained. Setups are separate from the program file; copying the executable alone does not move your library.

### Notes

Windows is unsigned. macOS is ad-hoc signed, not Developer ID signed or notarized; see the installation guide for first-launch prompts. Native packages are built automatically; manual desktop workflow verification has been performed on Windows. Linux downloads are x64, with an ARM64 source builder available.

The calculations are idealized setup estimates. No-load speed and stall force describe different operating points. Acceleration excludes grip, rotating inertia and drag. These results do not predict actual lap times or replace physical clearance/parts checks.
