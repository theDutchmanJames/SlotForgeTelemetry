**SlotForge Telemetry 0.8.1 introduces the new Gear & dial app icon.**

The gear-shaped speedometer brings mechanical setup and performance together. It replaces the stopwatch in the app header, desktop packages and README. The README also features the SlotForge App Collection logo and links to the other apps.

This is a visual update. Calculations, lap analysis, saved libraries and Paddock integration work as before.

### Choose your download

| Computer | File in Assets |
| --- | --- |
| Windows, 64-bit Intel/AMD | **SlotForgeTelemetry-0.8.1-windows-x64-Portable.exe** — save, then double-click. |
| Apple Silicon or Intel Mac | **SlotForgeTelemetry-0.8.1-mac-universal.dmg** — open and drag into Applications. The ZIP contains the same app. |
| Ubuntu / Debian / Mint, x64 | **SlotForgeTelemetry-0.8.1-linux-amd64.deb** — open with your software installer. |
| Other Linux desktops, x64 | **SlotForgeTelemetry-0.8.1-linux-x86_64.AppImage** — allow execution in Properties, then open. |

No Terminal or coding is required. GitHub's **Source code** archives are for developers. `SHA256SUMS.txt` provides download integrity checksums.

### Updating

Back up your setup library and manual laps, close the old app, then install or open the new version. Existing profiles, setups, lap data and themes are retained.

Windows is unsigned; macOS is ad-hoc signed and not notarized. The [installation guide](https://github.com/theDutchmanJames/SlotForgeTelemetry#download-and-install) explains first-launch prompts.
