**SlotForge Telemetry 0.15.0 rebuilds the app around your laps and your changes: every run on one Laps wall, a Setups page that says what a change does, a Library binder, a new Track day, and the shared SlotForge look.**

### Laps: every run on one wall

Six lap pages are now one. Pick a car, then a track and lane, and every run lands on one wall, whether it came from Paddock, Track day or was typed in. Each lap is a coloured square, from green at the record to red. The page also shows the record, the pace now, how much you gained, what changed between runs (such as *pinion 9 → 10*) and which changes moved the pace. Every run can have a note and a kind (Practice, Race, …), kept apart from imported races.

### Setups: what does this change do?

Analyze is now **Setups**. Compare up to three setups, including the workbench as it is now, to see a change before you save it. You get a plain verdict ("quicker on the straight, pulls less out of a corner"), the inputs you changed, and only the results that moved, marked green or red. There is also a new result: pull per kg.

### Library, Track day, Driver Feedback and the workbench

- **Library:** every setup in one list, grouped by car, with the best lap driven on that gearing. Star favourites, tick several to compare, export or delete them, and find cars and tracks on the same page.
- **Track day:** each run of the day is a column. Change pinion, gear, weight and tyre with + and − (Telemetry records the change for you), type one lap per box, and use *Keep this change* to put the quickest run's setup back on the workbench.
- **Driver Feedback:** one page that builds up as you answer: picture cards for what the car does, short questions, a checklist, then three suggestions. One click sends a suggestion to Track day.
- **Workbench:** each input sits beside the results it affects. Once the setup is saved, each row shows what your change did.
- **Calculation Map:** a clickable map of how your inputs become results, with each formula filled in with your numbers. A **?** next to a number opens it.
- **Connect to Paddock:** one card shows whether you are connected and the one action you need, plus your last eight imports.

### The SlotForge look

Telemetry now shares its style with Timing and Paddock: the same title and number fonts, buttons, focus ring and tables, a slim top bar with status lights, and a Settings side list with quick unit toggles.

### Updates

Telemetry looks for a new version once at start. A window shows what is new and can download the file for your copy into your Downloads folder, with progress and a completeness check. Nothing is ever installed automatically, and **Settings → Updates** has *Check now* and a switch for the check.

### Safer data and fixes

- **Restores:** a restore interrupted by a crash or power cut is finished at the next start, so your data is never a mix of old and new. A full disk changes nothing. A backup with one unreadable file can still be restored.
- **Paddock imports:** a dropped connection during an import from Paddock on this computer now changes nothing, instead of saving with races missing.
- **Saves:** Telemetry tries again when Windows briefly holds a file, and clears leftovers of cut-off saves at start.
- **Library size and speed:** the Library now holds 500+ setups (it filled up at about 300), reads a large library about six times faster, and searches runs more quickly.
- **Smaller fixes:** source links under Driver Feedback advice open in your browser, a hidden invalid value no longer blocks Save without a message, values stay in your units, and about a dozen other page fixes.

### Review and compatibility

Local validation passed 292 automated tests and all 24 desktop suites. It also included new random-action and crash tests, network-cut tests, a 45-minute long run and a random-click run through the whole app.

Existing setups, lap data and backups remain readable. Favourites and run notes are stored so that older versions open the files and ignore them.

### Choose your download

The Windows files have new names, the same pattern as the other SlotForge apps.

| Computer | File in Assets |
| --- | --- |
| Windows, 64-bit Intel/AMD | **SlotForgeTelemetry-0.15.0-Setup-x64.exe**: installs with Start menu and desktop shortcuts. Or **…-Portable-x64.exe** to run without installing. |
| Apple Silicon or Intel Mac | **SlotForgeTelemetry-0.15.0-mac-universal.dmg**: open and drag into Applications. The ZIP contains the same app. |
| Ubuntu / Debian / Mint, x64 | **SlotForgeTelemetry-0.15.0-linux-amd64.deb**: open with your software installer. |
| Other Linux desktops, x64 | **SlotForgeTelemetry-0.15.0-linux-x86_64.AppImage**: allow execution in Properties, then open. |

GitHub's **Source code** archives are for developers. **SHA256SUMS.txt** contains checksums for the downloads.

### Updating

Close Telemetry and replace the old application with the new download, or run the installer. Your data is kept, and Telemetry makes a backup automatically.

See the [installation instructions](https://github.com/theDutchmanJames/SlotForgeTelemetry#how-to-install) for platform-specific help. Windows and macOS builds are not publisher-signed or notarized; the README explains the operating-system prompts.
